# GOON SMP – server resource pack

Sent automatically by the GOON SMP Minecraft server (Survival, BedWars).

* `goon:hacker_alert` – alarm + voice "Има хакер в сървъра!", played to everyone when the anti-cheat (GrimAC) detects a cheat.

`goon-smp-sounds.zip` is the pack the server sends; `src/` is its source.
